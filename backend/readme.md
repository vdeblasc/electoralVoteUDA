# 🗳️ API Gateway - Sistema de Votación UDA

Este es el backend (Capa 2) del sistema de votación inmutable desarrollado para el **Sprint 1**. Funciona como un puente entre la interfaz de usuario (Frontend) y la red **Hyperledger Fabric**.

## 🚀 Tecnologías
- **Runtime:** Node.js v18+
- **Lenguaje:** TypeScript
- **Framework:** Express.js
- **Blockchain SDK:** fabric-network v2.2.x
