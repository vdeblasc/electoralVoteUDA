🗳️ Sistema de Votación Basado en Blockchain (dApp)
Este proyecto es una Aplicación Web Descentralizada (dApp) desarrollada para la cátedra de Base de Datos Avanzada. El objetivo principal es proporcionar un mecanismo de votación digital inmutable, transparente y criptográficamente seguro, mitigando riesgos de fraude mediante el uso de Smart Contracts en la red Ethereum.

🚀 Propósito del Sistema
El sistema permite gestionar procesos electorales de opción múltiple con un padrón cerrado, asegurando que cada voto sea único, secreto y auditable de forma pública sin intermediarios.

🛠️ Tecnologías Utilizadas
Blockchain: Solidity (Smart Contracts)

Red: Ethereum (Testnet Sepolia/Hardhat)

Web3 Integration: Ethers.js / Web3.js & MetaMask

Frontend: React.js (o la tecnología que estén usando)

Herramientas de Desarrollo: Hardhat / Truffle

📋 Características Principales
Conexión Web3: Autenticación mediante wallets digitales (MetaMask).

Padrón Cerrado (Whitelisting): Solo las direcciones autorizadas por el Administrador Electoral pueden emitir votos.

Inmutabilidad: Una vez emitido el voto, se registra en la blockchain y no puede ser modificado ni eliminado.

Transparencia: Recuento de votos en tiempo real auditable on-chain.

Control de Comicio: Funciones administrativas para iniciar y finalizar el periodo de votación.
